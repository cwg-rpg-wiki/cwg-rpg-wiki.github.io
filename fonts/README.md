# Local fonts

These variable WOFF2 fonts supply the Latin and Latin Extended subsets referenced by `index.html`. They are served locally; the site does not contact a font service.

Sources (Fontsource packages distributed through jsDelivr):

- Fraunces: `@fontsource-variable/fraunces@5.3.0`
- Source Sans 3: `@fontsource-variable/source-sans-3@5.3.1`
- JetBrains Mono: `@fontsource-variable/jetbrains-mono@5.3.0`

Download URL pattern:
`https://cdn.jsdelivr.net/npm/@fontsource-variable/{family}@{version}/files/{family}-{subset}-wght-normal.woff2`

The local filenames retain the names expected by the saved site's CSS. Their suffixes are historical, not checksums of these replacement files.

Each font's SIL Open Font License is included in its corresponding `*-LICENSE.txt` file.
